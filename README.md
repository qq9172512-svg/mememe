# 不動產經紀人 國考勝率戰略系統 (GitHub Pages / Android / iOS PWA App)

歡迎使用**不動產經紀人 國考勝率戰略系統**！本專案包含 114~110 年全科目完整歷屆考古題、150 題申論拆解、35 天速成地圖、講義生活圖卡與考霸小怪獸養成系統。

## 🌟 GitHub Pages 免費線上 App 部署教學

1. 將本專案儲存庫推送到您的 GitHub 帳號（例如：`broker-exam-app`）。
2. 在 GitHub 儲存庫頁面點擊 **Settings 🠖 Pages**。
3. 在 **Build and deployment 🠖 Branch** 選擇 `main` 分支並點擊 **Save**。
4. 1 分鐘後即可取得您的專屬線上 App 網址：`https://<username>.github.io/broker-exam-app/app.html`。
5. 開啟手機或平板瀏覽器，點選「**加入主畫面**」，即可全螢幕體驗離線 PWA 行動 App！
